Volley Mindset — Game-Day Checklist
Mindset · Pre-partido

Antes del partido:
[ ] Revisar objetivos del partido (1–3 puntos claros)
[ ] Rutina de respiración (2–3 minutos)
[ ] Visualizar el primer saque y las primeras 3 jugadas
[ ] Checklist físico: calentamiento, hidratación, equipo listo
[ ] Frase de ancla: "Un punto a la vez"

Durante el partido:
[ ] Reset después de cada error (exhala + siguiente acción)
[ ] Comunicación clara con el equipo
[ ] Mantener la misma energía entre puntos

Después:
[ ] Anotar 2 cosas que salieron bien
[ ] Anotar 1 ajuste para el próximo entrenamiento
